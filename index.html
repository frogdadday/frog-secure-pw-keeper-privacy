Frog Secure PW Keeper Privacy Policy

Free. Simple. Respectful.

Effective date: October 10, 2026
Last clarified: October 28, 2026 (explanatory wording; no change to the app’s data practices)

The short version

Frog Secure PW Keeper is an offline password safe. It does not collect, transmit, sell, or share personal information. It has no ads, analytics, accounts, subscriptions, cloud service, or internet permission.

Information stored on your device

The passwords, usernames, websites, and titles you enter are stored in the app’s private storage on your Android device. Vault data is encrypted with AES-256-GCM. PBKDF2-HMAC-SHA256 (600,000 iterations and a random 128-bit salt) derives a 256-bit key from your master password; the local vault also has a separate Android Keystore encryption layer, using StrongBox when available. The master password is not stored. Read the security design and limitations.

Network access and tracking

The app does not request Android’s INTERNET permission or contain network code. I operate no account system or server for the app. It contains no advertising, analytics, telemetry, tracking SDKs, or social features.

Clipboard

When you choose to copy a username or password, the app marks the clipboard item as sensitive and schedules it to clear after 20 seconds. Android may delay clipboard access while the app is in the background, and keyboards or other apps may keep their own clipboard history. The app cannot control data retained by another app.

Encrypted backup files

Backups are created only when you manually export one. Each portable .gpv backup is encrypted using the master password in effect when it was exported. Restoring it later requires that same password. This app version does not offer a master-password change feature, and creating or restoring a vault with a different password does not change the password protecting older exported backups. Android’s file picker lets you choose where to save the file. If you choose a cloud-storage provider, that provider may upload the encrypted file under its own privacy policy; the app itself does not upload it.

Android backups and permissions

Automatic Android backup is disabled for the app, and it provides no cloud sync or built-in phone-to-phone transfer. The only supported way to move your vault to a new phone is to export an encrypted .gpv backup from the old device, transfer the file, and import it on the new device using that backup’s master password. Without an exported backup, a lost, reset, or damaged phone can mean permanent loss of your vault. No storage permission is requested; manual import and export use Android’s system file picker, which grants access only to the selected file. The app requests no runtime permissions.

Autofill and accessibility

The app does not provide an Android Autofill service or run an accessibility service. It excludes its sensitive fields from Android Autofill. The standard interface remains usable with accessibility tools enabled by the device owner.

Data deletion

When a deletion saves successfully, the entry is removed from the current encrypted vault file. Older exported backups may still contain that entry, and flash storage may retain older encrypted blocks; the app does not promise secure physical erasure of every previous copy. Uninstalling the app or clearing its app data removes the local vault from that device. Encrypted backups you exported remain wherever you saved them and must be deleted there by you.

Children's privacy

The app does not knowingly collect information from anyone, including children.

Changes to this policy

If the app’s privacy behavior changes, I will update this policy before releasing the changed version and revise its effective date. Wording-only clarifications are identified by the “Last clarified” date above.
